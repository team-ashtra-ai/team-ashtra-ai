# Start here

This package contains the deployable ASH-TRA Languages Brazil website rebuilt in the visual system of the original ash-tra.com site.

## Main deliverables

- The website begins at `/index.html`.
- The complete academic programme page is `/study/index.html`.
- The editable academic programme document is `ASH-TRA_Complete_Academic_Programme_Website_Page.docx`.
- Detailed public-safe curriculum files are stored under `programme/`.
- Original-site screenshots and header/footer references are stored under `design-reference/`.
- All earlier editable content-planning documents from this conversation are preserved inside `archive/ASH-TRA_All_Previous_Content_Documents.zip`.
- Deployment checks and company facts are stored under `setup/`.

Read the root `README.md`, run `python3 docs/setup/check_site.py`, and test the site locally before publishing.


## 50-article blog edition

- Main blog: `/blog/`
- Ten categories: `/blog/category/<category>/`
- Fifty articles: `/blog/<seo-slug>/`
- Original hero images: `/assets/media/blog/`
- RSS feed: `/blog/feed.xml`
- Article index and word counts: `/docs/BLOG_ARTICLE_INDEX.csv`
- Research record: `/docs/EDITORIAL_RESEARCH_SOURCES.md`

The header and footer both contain a Blog link. Each article has one original top image, H1–H3 structure, 1,500–2,000 words and a unique CTA.
