# Original ASH-TRA design system preserved

The rebuild uses the original website as its visual reference rather than replacing it with a separate language-school theme.

Preserved characteristics:

- dark navy and midnight-blue backgrounds;
- neon-blue outlines and subtle blue glow;
- coral-to-gold primary calls to action;
- Syne headings, Manrope body copy and IBM Plex Mono labels;
- floating rounded header and pill navigation;
- large editorial hero headings;
- glass and bordered surfaces;
- rounded cards and cinematic spacing;
- Site Atlas mega-footer;
- shared CSS/JavaScript architecture and reusable header/footer partials.

Only the page content, routes and programme functions have been changed for ASH-TRA Languages Brazil.
